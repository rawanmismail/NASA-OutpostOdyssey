## 🌕 About the Project

**Outpost Odyssey** is an interactive lunar exploration and survival game inspired by NASA's hackathon challenge of establishing a sustainable human presence on the Moon.

Set near the lunar South Pole, players take responsibility for a crew of astronauts and work towards building and maintaining a functioning lunar outpost. Through exploration, resource management and mission decisions, players experience some of the environmental and operational challenges of living on the Moon.

The project combines an interactive 3D environment with educational content, mission-based gameplay and scientific references.

## 🎮 Getting Started

There are two ways to experience Outpost Odyssey.

### Option 1 — Play Online

The easiest way to get started. No downloads, installation or setup required.

**https://outpost-odyssey.up.railway.app/** or **https://outpostodysseygame.netlify.app**

Open the link in your browser and begin your mission.

### Option 2 — Install and Run Locally

Prefer to run the game on your own computer or explore the source code? Follow these steps.

**Prerequisites**

- Node.js **22.12 or newer**
- npm

**1. Clone the repository**

```bash
git clone <repository-url>
```

**2. Navigate into the project folder**

```bash
cd <repository-folder>
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the game**

Visit the local address displayed in your terminal, usually:

```text
http://localhost:5173/
```

Keep the terminal running while playing. Press `Ctrl + C` to stop the development server.

**Run tests and build the project**

```bash
npm test
npm run build
```

The production build is generated in the `dist` directory.

## 🌑 Mission Overview

Your mission takes place near the Moon's South Pole, an area of particular interest for future lunar exploration.

As the commander of your crew, you must:

- Explore the lunar surface and investigate potential landing sites.
- Select a suitable location for your outpost.
- Construct and upgrade essential infrastructure.
- Manage oxygen, water and electrical power.
- Operate equipment and complete daily mission objectives.
- Use a rover to explore routes, conduct scans and investigate potential water-ice resources.
- Respond to environmental hazards and unexpected emergencies.
- Make decisions that affect your crew's safety and mission success.

Every decision contributes to the survival and sustainability of your outpost.

## 🔬 Scientific Inspiration 

The project draws on lunar science, NASA resources and research relating to the Moon's South Pole.

Scientific topics represented in the game include:

- Lunar terrain, elevation and slope.
- Permanently shadowed regions and sunlight availability.
- Water ice and potential lunar resources.
- Radiation and environmental hazards.
- Oxygen, water and food requirements for long-duration missions.
- Solar power and outpost sustainability.

The scientific references and attributions are available in the game's science guide and project documentation.

**Scientific note:** Terrain, distances, resource values, costs, timers and mission outcomes are simplified game representations. They are not engineering simulations or official NASA measurements.
